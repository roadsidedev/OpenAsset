# Developer guide

OpenAsset is a permissionless lending protocol for isolated markets. Developers can build new markets and integrations around ERC-20s, NFTs, tokenized real-world assets, and other assets by selecting asset, oracle, compliance, liquidation, and position adapters.

The core engine retains loan state, accounting, circuit breakers, reentrancy protection, and defensive output checks. Adapters provide bounded integrations at an explicit trust boundary. A registry badge is not a substitute for on-chain validation or independent risk assessment.

## Developer journey

1. **Understand:** read the [protocol overview](/docs/learn/overview), [adapter system](/docs/build/adapter-system), and [security model](/docs/security/model).
2. **Install:** clone the repository, install `contracts` and `sdk` dependencies, and compile locally.
3. **Choose a starting point:** use the [reference adapters](/docs/build/reference-adapters) or generate an SDK scaffold.
4. **Implement:** follow the [adapter security model](/docs/security/model), including factory permissions, market isolation, fail-closed behavior, and non-upgradeable deployment.
5. **Test:** use the local [testing environment](/docs/build/quickstart#5-test) with mock assets, feeds, compliance, liquidation, failures, and gas checks.
6. **Submit:** run automated checks, record the source commit and dependencies, register metadata, and follow the [verification workflow](/docs/build/adapter-registry#review-meaning).
